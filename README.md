# DiversScout Environmental Logger (M5StickC Plus)

## 概要
`Environmental_logger_stickcp` は、DiversScoutプロジェクトにおけるデータ収集を担うエッジデバイス用のファームウェア・ロガープログラムです。
M5Stackシリーズの「M5StickC Plus」を利用し、屋外のバリアフリートイレなど、車椅子で長時間立ち寄る場所の環境データ（位置情報、傾斜、加速度など）を記録・収集します。

## 主な機能
- **センサーデータのロギング**: 温湿度、気圧などを測定できる環境センサーの測定値を継続的に取得します。
- **ポータビリティ**: M5StickC Plusの小型・軽量な特性を活かし、車椅子で立ち寄るスポットに容易に設置でき、利用者の健康を害する情報の収集を容易にします。
- **エコシステム連携**: 本デバイスで収集された生データ（ログ）は、バックエンドのワーカーシステムによる解析を経て、ビューア上でスポット情報として可視化されます。

## ハードウェア構成と依存関係
### 対象デバイス・センサー
- **ベースデバイス**: M5Stack M5StickC Plus
- **外部センサー**: Env3（温湿度・気圧センサー）

### ピン配置・配線（参考）
外部モジュール（GPSユニット等）接続時の標準的なピンアサインは以下の通りです。
- **通信インターフェース**: Groveポート（G32, G33）または拡張ピン（G0, G26等）を使用
*(※実際のハードウェア配線に合わせてソースコード内のシリアル通信ピン定義を確認・変更してください)*

### 依存ライブラリ
Arduino IDE環境でのコンパイルには、以下の主要ライブラリのインストールが必要です。
- `M5StickCPlus2` (または `M5Unified`): 本体制御・ディスプレイ描画用
- `M5Unit-ENV` (または類似のEnv3用ライブラリ): 温湿度・気圧データの取得用

## システムの目的と構成
本コンポーネントは、DiversScoutシステム全体における「物理空間からの一次データ抽出」を担う最前線のノードです。
街歩きやマッピング活動を通じて路面やスポットの環境状態をデジタルデータとしてサンプリングし、誰もが安全に移動・利用できるアクセシビリティマップを構築するための基礎データを提供します。

*(※ 本リポジトリはハードウェア側でのデータ収集実装を提供しています。収集済みデータの解析・データベース格納や、地図上での可視化については、それぞれの関連プロジェクトを参照してください。)*さい。)*
